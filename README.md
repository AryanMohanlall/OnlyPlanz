# BuildLink Network

Create a high-fidelity, mobile-first mock application called OnlyPlanz.

OnlyPlanz is a social networking and property collaboration platform for the building and real-estate industry. It connects property owners and people planning renovations with trusted architects, engineers, project managers, contractors, interior designers, quantity surveyors, property developers, real-estate professionals, and other construction specialists.

The primary experience should combine:

Industry networking

Property and architecture discovery

Professional recommendations

Renovation assistance

Project collaboration

Service-provider discovery

This is a frontend mock application. Use realistic sample data, placeholder images, and simulated interactions. Do not require a functional backend.

Target users

Support the following user types:

Property owners

Architects

Civil and structural engineers

Project managers

Contractors and builders

Interior designers

Quantity surveyors

Property developers

Real-estate agents

Building suppliers and specialists

Users should be able to select one or more professional roles during onboarding.

Design direction

Design a premium, trustworthy, modern mobile interface inspired by the visual quality of LinkedIn, Instagram, Houzz, Pinterest, and Airbnb, without directly copying them.

Use:

A warm, architectural colour palette

Off-white or light stone backgrounds

Charcoal text

Muted green, terracotta, or deep navy accents

Rounded cards with subtle shadows

Large property and project photography

Clean sans-serif typography

Generous spacing

Clear status badges and trust indicators

Smooth transitions and subtle micro-interactions

The interface should feel professional and suitable for both homeowners and construction-industry experts.

Build the application for a mobile viewport, approximately 390 × 844 pixels, while keeping components responsive.
